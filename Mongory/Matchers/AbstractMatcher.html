Overview

This class is abstract.

Subclasses must implement #match to define their matching logic

AbstractMatcher is the base class for custom Ruby matchers in Mongory.

Built-in operators are implemented natively in mongory-core. Subclass AbstractMatcher and register it with Mongory::Matchers.register to extend Mongory with custom operators evaluated via the mongory-core custom matcher bridge.

Examples:

Custom matcher implementation

class DivisibleByMatcher < Mongory::Matchers::AbstractMatcher
  def match(record)
    record.is_a?(Numeric) && (record % @condition).zero?
  end

  def check_validity!
    raise Mongory::TypeError, '$divisibleBy needs a non-zero Integer' unless
      @condition.is_a?(Integer) && @condition != 0
  end
end

Mongory::Matchers.register(:divisible_by, '$divisibleBy', DivisibleByMatcher)
