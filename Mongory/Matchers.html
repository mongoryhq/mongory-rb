Overview

Provides custom matcher registration and Symbol operator snippet management.

Built-in operators are evaluated natively by mongory-core and registered in BUILTIN_OPERATORS so enable_symbol_snippets! can expose Symbol methods (e.g., :age.gt, :tags.in).

Custom Ruby matchers subclassing Mongory::Matchers::AbstractMatcher are registered via Matchers.register(method_sym, operator, klass) and bridged into mongory-core through Matchers.lookup(operator).

def self.register(method_sym, operator, klass)
  Validator.validate_method(method_sym)
  Validator.validate_operator(operator, klass)
  Validator.validate_class(klass)

  @operator_mapping[operator] = klass
  registry = Registry.new(method_sym, operator).freeze
  @registries << registry
  return unless @enable_symbol_snippets

  registry.apply!
end
