Overview

Core query matcher backed by the mongory-core C99 native extension.

Examples:

matcher = Mongory::Matcher.new(age: { :$gte => 18 })
matcher.match?(age: 20) #=> true
# or
collection.mongory.where(age: { :$gte => 18 }).to_a
